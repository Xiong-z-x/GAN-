## 4. 报告写法边界

- DCGAN / DCGAN++：课程 baseline 和改进实验。
- StyleGAN3：官方 FFHQ 预训练 GAN 上限展示，不是本项目训练。
- AnimeGANv2 / CycleGAN：GAN 风格迁移扩展，不进入 DCGAN FID 主表排序。
- InstantID：扩散模型身份保持扩展，不是 GAN。
- 轻造型保脸：关键点后处理，不是 GAN 生成，也不是 InstantID 训练结果。
- GFPGAN：人脸修复/清晰化后处理，不负责身份保持。
