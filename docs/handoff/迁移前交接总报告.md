## 1. 项目总目标

本项目是深度学习课程中的 GAN 真实人像生成大作业。当前目标分为两条线：

1. **课程实验线**：用 DCGAN / DCGAN++、StyleGAN3、AnimeGANv2、CycleGAN 构成从基础 GAN 到高质量 GAN 和风格迁移的递进实验。
2. **应用封装线**：用 FaceGAN Studio 封装一个 Gradio Web 程序，统一展示和调用四类能力：DCGAN/DCGAN++、StyleGAN3、AnimeGANv2/CycleGAN、InstantID/GFPGAN 方向。

需要保持的技术边界：

- DCGAN / DCGAN++ 是课程 baseline，不承诺达到 StyleGAN3 质量。
- StyleGAN3 是官方 FFHQ 预训练权重复现，展示成熟 GAN 上限。
- AnimeGANv2 / CycleGAN 是风格迁移模块。
- InstantID 是身份保持应用扩展，不是 GAN baseline。
- GFPGAN 已在 AutoDL 接入并验证，但只能写作人脸修复/清晰化后处理，不能写作身份保持模型。
- StyleGAN2-ADA 人脸反演 + 潜空间编辑已尝试但因身份偏差取消，不作为当前交付模块。

## 3. 当前代码状态

### 3.1 DCGAN / DCGAN++

核心目录：

```text
src/dcgan/
scripts/run_dcganpp_suite.sh
scripts/monitor_dcganpp_progress.py
```

已实现能力：

- baseline DCGAN。
- Hinge loss、谱归一化、EMA、DiffAugment。
- 残差块、自注意力、R1 regularization。
- E0-E4 实验脚本。
- 训练进度监控脚本。

风险：

- 经典 DCGAN 画质上限有限，不能通过话术包装成高质量人像生成。
- DCGAN++ 长训练成本高，结果不稳定，需要用报告语言诚实表述。
- 恢复训练时必须确认监控脚本读取的是当前 resumed output directory。

### 3.2 StyleGAN3

核心脚本：

```text
scripts/run_stylegan3_generate.sh
scripts/run_stylegan3_video.sh
```

定位：

- 使用官方 FFHQ 预训练权重生成高质量人像。
- 展示现代 GAN 上限和潜空间连续性。

风险：

- StyleGAN3 与 CelebA_64 的 FID 属于跨域参考，不可作为公平排序依据。

### 3.3 AnimeGANv2 / CycleGAN

核心脚本：

```text
scripts/run_animegan2_infer.sh
scripts/run_cyclegan_pretrained_style.sh
scripts/prepare_style_transfer_inputs.py
```

已处理风险：

- CycleGAN 脚本已去掉旧版 `--gpu_ids` 参数，适配当前官方 `test.py`。
- 个人照片路径可递归扫描，能处理 `data/raw/my_photos/my_photos/` 这种嵌套结构。

风险：

- 风格迁移结果不参与真实人像 FID 主指标。
- 不要混淆首次结果和重跑结果，输出目录应按任务单独命名。

### 3.4 InstantID

目标：

- 输入个人照片，生成同一身份的不同姿态、造型和场景。

AutoDL 端必须存在：

```text
external/InstantID/checkpoints/ControlNetModel/diffusion_pytorch_model.safetensors
external/InstantID/checkpoints/ip-adapter.bin
external/InstantID/models/antelopev2/
```

并且需要本地 SDXL 基础模型，例如：

```text
/root/autodl-fs/models/YamerMIX_v8
```

风险：

- 历史上 Hugging Face 大模型在线拉取出现过 503 和低速下载。
- 推理代码应使用本地模型路径和 `local_files_only=True`。
- 不要直接安装官方 demo requirements 覆盖当前 PyTorch 环境。
